# student-portfolio-ai-challenge.
AI-assisted student portfolio project.
Student Portfolio — AI Integration Challenge

Project Goal

Create a minimalist student portfolio that presents education, skills, interests, projects, and future goals.

Tools Used

- ChatGPT: helped plan and organize the project.
- Canva: used to design the student portfolio.
- Notion: used to organize the project plan and checklist.
- GitHub: used to document the workflow and store project files.

Workflow

1. Plan the portfolio structure.
2. Organize tasks in Notion.
3. Design the portfolio in Canva.
4. Export the final document as a PDF.
5. Document the process and evidence in GitHub.

Evidence Checklist

- [ ] Canva portfolio screenshot
- [ ] Final PDF
- [ ] Notion project plan
- [ ] GitHub repository
- [ ] Explanation of how the tools worked together

Accuracy

Use real personal information and genuine achievements only. Do not invent experience or qualifications.

Status

Project documentation in progress.
